# JW163 | From SAP Fiori elements to agent to Joule Work: The full stack, hands-on

## Description

This repository contains the material for the SAP TechEd 2026 session **JW163 - From SAP Fiori elements to agent to Joule Work: The full stack, hands-on**.

## Overview

In this session you build an SAP Fiori app with SAP Fiori elements and AI tooling, see how an agent can reuse that app's OData service to surface business data, and watch how Compositional UI turns your data into enterprise UI at runtime in Joule Work.

The idea behind the session: the custom SAP Fiori apps and OData services you already build are not legacy to be replaced. They are machine-readable business knowledge that an AI can reuse. The OData service, its annotations, and its actions describe what the data means, how it connects, and what a user can do with it. When an AI reuses that description, it produces best-fitting results and output that looks familiar to users who already know the app. You experience this across three parts.

## The three parts

- **Part 1 - Build a custom SAP Fiori app.** Using SAP Business Application Studio and its AI tooling, you generate a working SAP Fiori elements application from an image and a data model. This gives you a custom app and an OData service: the business knowledge the later parts build on.

- **Part 2 - From app to agent.** Using SAP Joule Studio, you see how the OData service behind a Fiori app can be reused by an agent to surface business data, and get a hands-on feel for how that works, using the SFlight scenario available in SAP Joule Studio.

- **Part 3 - Compositional UI.** You get a labs preview of the CompUI tooling, to see how AI assembles enterprise UI from your data at runtime, and how that same rendering powers the experience in Joule Work.

By the end you will have built a custom Fiori app with AI tooling, seen how its OData service can be reused by an agent, and seen how Compositional UI renders that data into enterprise UI. The apps you already invest in make your Joule Work experience better, not obsolete.

## Requirements

The requirements to follow the exercises in this repository are provided at the start of each part. In general you need a modern browser and the pre-provisioned workshop accounts handed out during the session. No local installation is required.
